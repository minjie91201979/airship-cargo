# 云港航运 · Airship Cargo

> 蒸汽朋克飞艇货运游戏（浏览器 3D）。驾驶一艘蒸汽飞艇，在夕阳下的云海之上穿梭于浮空群岛之间，承接货运委托、赚取报酬、升级你的飞艇。

当前版本：**v1.3.0**（新区域与船体：北方的霜原群岛与强风墙、寒冷机制、冰鲜 / 跨区长途委托、三种船体与船坞、霜原篇「霜原来信」，详见「v1.3 新内容」与文末「更新日志」）

## 快速开始

需要 Node.js 18+。

```bash
npm install        # 安装依赖
npm run dev        # 开发服务器（浏览器打开终端里显示的地址）
npm run build      # 类型检查 + 生产构建（输出到 dist/）
npm run preview    # 本地预览构建结果
npm run dist:win   # 打包 Windows exe（便携版 + 安装版，输出到 release/，需在 Windows 上运行）
npm run sim        # 平衡性模拟（无界面，打印各章用时与银币曲线）
```

## v1.0 功能总览

- **飞行**：锅炉压力（浮力）、螺旋桨档位、方向舵三套独立操纵，有惯性、风场、气流带、载重影响；煤水消耗与补给，永不卡死的紧急拖航。
- **群岛**：10 座各具特色的浮空岛，小地图 / 全图，到达横幅，航区边界。
- **经济**：四类货物（普通 / 易碎 / 加急 / 超重），委托公告板、结算、声望、燃料差价；存档自动保存。
- **改装**：锅炉 / 气囊 / 螺旋桨 / 货舱 / 装甲各 4 级，外观随等级变化；8 套涂装；船体耐久与修理。
- **天气与险情**：18 分钟一昼夜（星月、夜灯、探照灯）；雷暴（湍流、下沉气流、雷击）；空贼追击与抛货；雾区与黎明晨雾。
- **主线**：序章 + 六章，重建云港航运公司、还清旧债，最终让云港灯塔复明；结局与片尾字幕后可自由经营。
- **成就**：20 项，独立保存；航运日志。
- **音效**：全部用 Web Audio 实时合成，没有音频文件。
- **设置**：音量、画质档位、操控灵敏度、界面选项、清除存档 / 成就。

## 游戏简介

- **飞行手感**：比街机直升机更沉、更有惯性。飞艇有质量与转动惯量，所有操作都需要提前量。
- **三套独立操纵**
  - **升力**：锅炉压力（加热气囊）决定浮力，约 50% 为中性浮力；压力变化有明显滞后。
  - **推进**：螺旋桨档位 -1（倒车）~ 4（全速），桨速逐渐爬升，速度受空气阻力限制。
  - **方向舵**：控制偏航，转向有惯性，低速时舵效下降，转弯时船体轻微外倾。
- **画面风格**：低多边形 + 铜/黄铜蒸汽朋克界面，云海、夕阳、灯塔光束。全部程序化几何体，无外部美术资源。

### 飞行规则

- 锅炉压力约 50% 时浮力与重力平衡；压力越高上升越快（实际压力每秒最多变化约 12%）。
- 接近 **420 米升限** 时空气稀薄，浮力下降，飞艇无法再升高。
- 低于 48 米会出现低空警告；**沉入云海**（低于 20 米）3 秒后，拖船会把飞艇拖到最近的港口（按紧急拖航收费与扣罚）。
- 撞到浮岛、建筑或栈桥会被柔和地弹开（软碰撞）。

## M1 新内容

### 煤与水
- 锅炉燃煤 = 怠速 + 锅炉压力项 + 桨速项；用水随蒸汽产生（压力、桨速）同步消耗。
- 正常巡航（压力约 55%、三档）满舱约 **5.5 分钟**；全压全速约 3.5 分钟。水箱比煤舱略耐用（约 7 分钟）。
- HUD 左下有煤 / 水玻璃管表与“续航”倒计时；低于 20% 时闪烁警告。
- **断煤**：锅炉熄火，压力每秒衰减约 1.4%，螺旋桨随之无力，飞艇慢慢下沉。
- **缺水**：锅炉压力上限降到 34%，飞艇无法维持高度。
- （M1 时补给免费；M2 起改为在港口面板付费购买。）

### 风场
- 全局微风（风向随时间缓慢摆动，越高越强）+ 4 条区域气流带：
  - **北境急流**（210–430 米，向东，最强约 9 米/秒）
  - **南环流**（50–210 米）
  - **峡口风**（清泉岛—煤矿岛之间，40–330 米）
  - **东岸下行风**（工坊城—芦苇礁一带）
- 阻力作用于飞艇相对空气的速度：顺风时地速更高、同样的煤能飞更远；逆风则缓慢、费煤；侧风会把船吹偏。
- HUD 风向盘：船头朝上，蓝色箭头为风吹去的方向，并显示风速与“顺风 / 逆风 / 左右舷侧风”和所处气流带。
- 视觉：镜头周围的风痕线（风越大越明显）与气流带中随风漂移的云絮。

## M2 新内容

### 经济与存档
- 存档用 zustand persist 写入浏览器 localStorage，键名 `airship-cargo.save.v1`：银币、各岛声望、货舱（4 个货位 / 最大载重 10 吨）、货物与完好度、各岛公告板、游戏时钟、最后停靠港口、煤水余量、统计（交付数、失败数、航程、总收入、总支出）。
- 开局 **300 银币**（M3 起调整为 150）。HUD 右上（小地图左侧）显示银币与当前载重。
- 主菜单：有存档时显示 **继续航行**（从上次停靠的港口继续）与 **新的航程**（面板内二次确认后清空存档）。

### 港口面板（靠泊后按 E）
- **委托**：每座岛按自身特色生成 3–5 个委托，发往其它岛屿。显示货物、类型、目的地、距离、重量、报酬与时限；货位或载重不足时无法接单。公告板约 5 分钟（游戏时间）整体刷新，被接走后再来时补足到至少 3 个。
  - 出口特色：云港（邮件、杂货、玻璃器皿）、煤矿岛（煤炭、铁矿石）、果园岛（鲜果、果酱）、工坊城（机械零件、精密仪表）、灯塔岛（灯油、航海日志）、风车岛（面粉、鸡蛋）、清泉岛（泉水桶、药草）、松风屿（松木、毛皮）、余烬岛（硫磺、火山玻璃）、芦苇礁（鱼干、芦苇席）。
- **货舱**：货位 / 载重条、当前货物（目的地、计时、完好度）、放弃委托（出发岛声望 -3）、统计与各岛声望。
- **补给**：煤 / 水按岛定价（煤矿岛煤 0.35 银币/1%，清泉岛水 0.10 银币/1%，偏远的芦苇礁、余烬岛最贵）；钱不够时买到买得起的量。身无分文且煤或水低于 25% 时，港务局提供免费救济（v1.1 起补到 60%，够飞到邻近岛屿）。
- 面板打开时游戏时间暂停；系泊时锅炉压火，耗煤只有正常的 15%。

### 货物类型
| 类型 | 规则 | 报酬系数 |
| --- | --- | --- |
| 普通货 | 期望时间内送达 +10% | ×1.0 |
| 易碎品 | 碰撞 / 撞击速度大于 2.2 米/秒的重着陆会降低完好度，按完好度扣款 | ×1.4 |
| 加急件 | 限时：提前送达最多 +25%；超时扣 50%；超过时限 1.5 倍时作废（出发岛声望 -3） | ×1.55 |
| 超重货 | 重量大（3–7 吨），明显吃浮力 | ×1.3 |

基础报酬 =（32 + 距离 × 0.065 + 重量 × 9）× 类型系数 ×（1 + 出发岛声望 × 0.5%）（v1.1；M3–v1.0 为 25 + 距离 × 0.05 + 重量 × 8）。时限：加急件 = 距离 / 9.5 + 60 秒，其它货的速度奖励期 = 距离 / 8.5 + 100 秒。

### 载重对飞行的影响
- 中性浮力压力 = 50% + 载重 × 2.6%（10 吨约 76%）；压力表绿色区与「压力归中」(X) 自动跟随。系泊时装卸货会自动调整目标压力，不会意外解缆。
- 质量系数 1 + 载重 × 6%：加速、转向、升降都更迟缓；推力略降；每吨额外耗煤。
- 吊舱后甲板堆放货箱（按类型配色，尺寸随重量变化），超重货用铁链挂在两舷。

### 交付
- 在目的地靠泊（E）时自动卸下所有发往该岛的货物，弹出结算卡：基础报酬、速度奖励、损坏扣款、超时扣款、声望、小计与合计。
- 声望：目的地岛 +2（完好且准时再 +1），出发岛 +1。
- HUD：左侧货舱委托列表（目的地、剩余时间 / 奖励期、完好度）；罗盘下方指向最近目的地的箭头与距离；目的地栈桥上有金色光柱、旋转菱形和扩散光环；小地图上目的地岛加金色圆环（超出范围时贴边显示）。

### 紧急拖航（永不卡死）
- 航行中连按两次 `H`：拖到最近的港口，费用 = 40 + 距离 × 0.05 银币（钱不够则收取全部，不会负债）；易碎品与加急件全部损失（出发岛声望各 -3；v1.1 起主线货物不会丢失）；煤水至少补到 20%。
- 沉入云海同样触发拖航。抵达后可在港口领取救济燃料、接普通 / 超重货继续赚钱。

### 其它
- 风痕从 1 像素线改为实例化的细长发光条（离镜头越远越粗），风大时清晰可见。

### 空贼
- 完成 **2 单**之前不会出现。之后，当货舱货值 ≥ 120 且离开港口安全区（各港口 330 米内）时，空贼按货值概率出现（货值越高越频繁，每次结束后有冷却）。

- 摆脱：全速 / 顺风甩开（拉开到 1 千米外）、爬升到 340 米以上（钩索进度回退）、钻进雷暴（空贼不敢跟）、飞进港口安全区；坚持 150 秒空贼也会放弃。成功甩脱的货物结算额外 +8%（「甩脱空贼」）。

- 空贼有 70 点耐久，可以被击落（坠落 + 爆炸），掉落 80–140 银币赏金与残骸。
- 炮弹为可见的橙色曳光弹，命中扣船体耐久（装甲按 `bumpRes × 90%` 减伤），命中气囊有概率**击穿**：
  - 每个破洞使中性压力 +3.5%（上限 +20%），HUD 显示「漏气」警告，要更多煤才能保持高度；
  - 在云港 / 工坊城「补给」页修补（每处 35 × 当地修理单价）。
- **对非战斗玩家友好**：没装机炮或鱼叉时，空贼只做“威慑射击”——追击 12 秒后才开火，每 10 秒 2 发、每发 3 伤害，击穿概率也从 28% 降到 12%。装了武器才会正面交火（每 6.5 秒 3 发）。逃跑手段（加速、爬到 340 米以上、钻雷暴、进港口安全区、抛货、照明弹）全部照旧有效。
- 船体耐久打空后再中弹：空贼直接钩走货物；如果正在执行委托战斗则被拖航回港，委托失败或暂停。

### v1.0.1（2026-10-03）—— 修复「到达目的地按 E 无法停靠」

**根因**：旧的靠泊判定过于严格且没有任何反馈——
- 距离按**三维直线距离**计算（含高度差），要求 ≤ 70 米。飞艇只要比栈桥高出四五十米，即使已经在栈桥正上方附近也会判定「太远」；
- 速度按**三维对地速度**计算（含升降速度和风漂），要求 < 4.5 米/秒（约 8.7 节）。在有风的航区，飞艇即使停桨也会随风漂移 3～8 米/秒，几乎不可能满足；HUD 显示的是水平速度，与判定口径不一致，玩家看到「8 节」仍然靠不上；
- 条件不满足时按 E **静默无效**，玩家不知道原因。

**修复**：
- 新的靠泊判定 `dockCheck()`：只算**水平距离**（≤ 90 米），高度窗口为高出系泊点 60 米～低于 25 米；速度取**水平地速与水平空速中较小者**，阈值放宽到约 12 节（6.2 米/秒），风漂不再阻止靠泊；
- 接近栈桥（225 米内）时 HUD 常驻提示：满足条件显示「按 E 靠泊 · X栈桥」，否则明确说明原因（太远 / 太高 / 太低 / 太快，并给出具体数值）；
- 条件不满足时按 E 会弹出提示说明无法靠泊的原因；
- 系泊缆绳改为限速收船（水平最快 6 米/秒；若低于泊位会先升高再横移），从 90 米外靠泊也不会蹭岛；
- 键盘输入统一使用物理键位 `e.code`（中文输入法开启时 `e.key` 会变成 "Process"，现在不受影响），极少数 `code` 为空的环境用 `keyCode` 兜底；焦点在设置滑块时方向键不再被游戏劫持；剧情卡片的 Enter / Esc 也走同一套键位解析。
- 自动化测试：在 10 座岛的栈桥附近（水平 50～80 米、高出栈桥 15 米、带侧风与残余速度）用真实键盘事件按 E，10 座岛全部靠泊成功。
